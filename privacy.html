개인정보처리방침 (Privacy Policy)

시행일 / Effective date: 2026-10-07

1. 개요

"feello"(이하 "앱")는 몸속비상회의 채널 운영자가 자신의 YouTube 채널에 직접 제작한 영상을 업로드하고 관리하기 위해 사용하는 내부 도구입니다. 앱은 일반 사용자를 대상으로 하지 않으며, 채널 운영자 본인의 Google 계정만 연결합니다.

2. 이용하는 정보

앱은 YouTube API 서비스(YouTube API Services)를 사용하며, 운영자가 승인한 범위 안에서 다음 정보에만 접근합니다.

  • 운영자 본인 채널의 기본 정보(채널 이름, ID) — 올바른 채널인지 확인하는 용도
  • 운영자 본인 채널의 동영상 업로드 및 메타데이터(제목, 설명, 태그, 공개 설정) 관리

앱은 다른 YouTube 사용자의 개인정보를 수집하지 않으며, 광고·판매·프로파일링 목적으로 어떤 데이터도 사용하거나 제3자에게 제공하지 않습니다.

3. 보관 및 삭제

OAuth 인증 토큰은 운영자의 기기에만 저장되며 외부 서버로 전송되지 않습니다. 운영자는 언제든지 Google 계정 보안 설정에서 앱의 접근 권한을 철회할 수 있고, 철회 시 저장된 토큰은 더 이상 사용할 수 없으며 기기에서 삭제됩니다.

4. Google 및 YouTube 정책

앱은 YouTube API 서비스를 사용합니다. 앱을 사용함으로써 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 데이터 처리 방식은 Google 개인정보처리방침을 따릅니다.

English summary

"feello" is an internal tool used solely by the owner of the Body Emergency (몸속비상회의) YouTube channel to upload and manage the owner's own videos via the YouTube API Services. It accesses only the owner's channel info and video upload/management within the scopes the owner grants. It does not collect data from other users, and no data is sold, shared, or used for advertising. OAuth tokens are stored only on the owner's device and can be revoked at any time at Google Account permissions. By using this app you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
